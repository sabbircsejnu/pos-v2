# REPORT_TABLE_STANDARDS

## Overview

This document defines the standard behaviour, layout, calculations, usability rules, and consistency requirements for all report tables across IraniMart POS V2.

This standard applies to all existing and future reports.

---

# Scope

This standard applies to:

- Sales Reports
- Inventory Reports
- Purchase Reports
- Supplier Reports
- Customer Reports
- Financial Reports
- Accounting Reports
- Dashboard Drill-Down Reports
- Audit Reports
- Custom Reports

---

# Core Principles

## Accuracy First

Report calculations must always represent the complete filtered dataset.

Pagination must never affect calculations.

## Consistency

All reports must follow identical table behaviour.

## Business Visibility

Important totals must remain visible while users browse report data.

---

# Table Layout Standards

Every report table should support:

- Sorting
- Pagination
- Search
- Column Resize
- Column Visibility Selection
- Horizontal Scrolling
- Row Hover State
- Sticky Header
- Sticky Footer Totals

---

# Sticky Footer Totals

## Requirement

Every report table must display a sticky footer row whenever one or more columns support aggregation.

The footer must remain visible at the bottom of the table while scrolling.

---

# Calculation Rule

Footer totals must always be calculated from the complete filtered dataset.

Footer totals must NOT be calculated from:

- Current Page
- Visible Rows
- Loaded Rows

Footer totals must be calculated from:

- Complete Filtered Dataset

---

# Example

Filtered Records: 5,000  
Page Size: 50  
Visible Rows: 50  

Correct footer total must be calculated from all 5,000 filtered records, not only the 50 visible rows.

---

# Aggregatable Columns

Totals should be shown for meaningful numeric columns such as:

- Quantity
- Sales Quantity
- Purchase Quantity
- Return Quantity
- Discount Amount
- VAT Amount
- Tax Amount
- Total Amount
- Paid Amount
- Due Amount
- Refund Amount
- Cost Amount
- Profit Amount
- Stock Value
- Inventory Value
- Transfer Quantity
- Adjustment Quantity

---

# Non-Aggregatable Columns

Totals must not be shown for:

- MRP
- Unit Price
- Product Name
- SKU
- Barcode
- Phone Number
- Email
- Reference Number
- Invoice Number
- Transaction Number
- Batch Number
- Serial Number
- Status
- Notes
- Remarks

---

# Footer Display Standards

Footer row must:

- Remain sticky
- Stay aligned with table columns
- Use bold text
- Have a visually distinct background
- Show formatted values
- Update immediately when filters change

---

# Pagination Standards

Pagination affects only row visibility.

Pagination must never affect:

- Totals
- Counts
- Averages
- Aggregations

---

# Filter Behaviour

Whenever filters change:

- Report data must refresh
- Footer totals must refresh
- Summary cards must refresh
- Export totals must refresh

All calculations must use the updated filtered dataset.

---

# Export Standards

Exported reports must include the same filtered dataset totals shown on screen.

Supported export formats:

- Excel
- CSV
- PDF

---

# Currency Formatting

Currency values must:

- Use system configured currency
- Use thousand separators
- Use configured decimal precision

Example:

৳ 1,250,000.00

---

# Quantity Formatting

Quantities must support:

- Integer quantities
- Decimal quantities

Examples:

10  
10.50  
125.750

---

# Summary Cards

Where applicable, reports should display summary cards above the table.

Examples:

- Total Sales
- Total Purchases
- Total Profit
- Total Quantity
- Total Orders
- Total Inventory Value

Summary cards must use the same filtered dataset as the table footer.

---

# Audit Requirements

The system should maintain:

- Generated By
- Generated Date
- Applied Filters
- Export History

---

# Acceptance Criteria

## AC-01

All report tables display sticky footer totals where aggregation is applicable.

## AC-02

Footer totals are calculated from the complete filtered dataset.

## AC-03

Pagination does not affect totals.

## AC-04

Changing filters recalculates footer totals.

## AC-05

Exported reports contain identical totals to the on-screen report.

## AC-06

Footer values remain aligned with table columns.

## AC-07

Currency and quantity values follow system formatting rules.

## AC-08

All existing and future reports comply with this standard.
