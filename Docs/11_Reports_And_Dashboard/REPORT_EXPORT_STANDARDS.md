# REPORT_EXPORT_STANDARDS

## Overview

This document defines the standard export behaviour for all reports across IraniMart POS V2.

The objective is to ensure exported reports are accurate, consistent, professional, and aligned with on-screen report data.

---

# Scope

This standard applies to all report exports including:

- Sales Reports
- Inventory Reports
- Purchase Reports
- Supplier Reports
- Customer Reports
- Financial Reports
- Accounting Reports
- Dashboard Drill-Down Reports
- Audit Reports
- Custom Reports

---

# Supported Export Formats

Reports should support:

- Excel
- CSV
- PDF
- Print

---

# Export Data Rule

Exported data must be based on the complete filtered dataset.

Export must NOT be limited to:

- Current page
- Visible rows
- Loaded rows

Export must include all records matching the applied filters.

---

# Export and Pagination

Pagination must not affect exported data.

Example:

Filtered Records: 5,000  
Page Size: 50  

Export must include all 5,000 filtered records.

---

# Export Totals

Exported reports must include the same totals shown in the report footer.

Totals must be calculated from the complete filtered dataset.

Examples:

- Total Quantity
- Total Discount
- Total VAT
- Total Amount
- Total Cost
- Total Profit
- Total Stock Value
- Total Paid
- Total Due

---

# Export Header

Exported reports should include a header section.

Header should include:

- Report Name
- Generated Date
- Generated By
- Outlet
- Warehouse
- Date Range
- Applied Filters

---

# Excel Export Standards

Excel export should include:

- Report title
- Applied filters
- Column headers
- Full filtered dataset
- Total row
- Proper number formatting
- Proper currency formatting
- Proper date formatting

---

# CSV Export Standards

CSV export should include:

- Column headers
- Full filtered dataset
- Total row where applicable

CSV should avoid styling because CSV is plain text.

---

# PDF Export Standards

PDF export should include:

- Company name
- Report name
- Generated date
- Generated by
- Applied filters
- Report data
- Total row
- Page numbers

PDF should be printable and readable.

---

# Print Standards

Print view should include:

- Report title
- Applied filters
- Data table
- Total row
- Generated date
- Page number

Print output should avoid unnecessary UI controls.

---

# Column Export Rule

By default, export should follow the visible report columns.

If column selection is available, the export should respect selected columns unless the user chooses Export All Columns.

---

# Formatting Standards

## Currency

Currency must follow system configuration.

Example:

৳ 1,250,000.00

## Quantity

Quantity must follow product quantity precision.

Examples:

10  
10.50  
125.750

## Date

Date must follow system date format.

Example:

07/06/2026

---

# Permission Rules

Export permissions must be controlled by role.

Possible permissions:

- View Report
- Export Excel
- Export CSV
- Export PDF
- Print Report
- View Cost
- View Profit

Users without cost permission must not see cost values in exported reports.

Users without profit permission must not see profit values in exported reports.

---

# Sensitive Data Rule

Exports must respect user permissions.

Sensitive values may include:

- Cost Price
- Profit
- Margin
- Supplier Cost
- Financial Amounts
- Customer Contact Details

Unauthorized users must not be able to export restricted data.

---

# Export File Naming Standard

Exported file names should follow a consistent format.

Recommended format:

REPORT_NAME_YYYYMMDD_HHMMSS

Examples:

SUMMARY_SALES_REPORT_20260607_153000.xlsx

CURRENT_STOCK_REPORT_20260607_153000.pdf

---

# Export Performance

Large exports should be handled carefully.

For large datasets:

- Use background export job if required
- Show export progress
- Notify user when export is ready
- Avoid browser timeout
- Avoid blocking the UI

---

# Audit Requirements

The system should record export activity.

Export audit should include:

- Report name
- Export format
- Exported by
- Exported date
- Applied filters
- Number of records exported

---

# Error Handling

If export fails, the system should show a clear error message.

Examples:

- Export failed. Please try again.
- Too many records. Please narrow your filters.
- You do not have permission to export this report.

---

# Acceptance Criteria

## AC-01

Export includes the complete filtered dataset.

## AC-02

Export is not limited by pagination.

## AC-03

Export totals match on-screen footer totals.

## AC-04

Export respects applied filters.

## AC-05

Export respects user permissions.

## AC-06

Cost and profit data are hidden from unauthorized users.

## AC-07

Export file names follow the standard naming format.

## AC-08

Large exports do not block the user interface.

## AC-09

Export activity is recorded for audit purposes.

## AC-10

PDF and print reports are readable and professionally formatted.
